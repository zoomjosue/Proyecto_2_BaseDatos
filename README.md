# Proyecto_2_BaseDatos

#  Sport GT — Tienda Deportiva

Aplicación web para gestión de inventario y ventas de una tienda deportiva.  

## Levantar el proyecto

### Pasos

```bash
# 1. Clonar el repositorio

# 2. Cambiar el nombre del archivo de variables de entorno quitarle el .example

# 3. Levantar todo con un solo comando
docker compose up --build
```
